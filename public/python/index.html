The learning path

Start with the basics. Build towards real projects.

A structured Python curriculum, organised into short lessons so learners can progress one concept at a time.

01 — FOUNDATIONS

Python Fundamentals

Introduction, installation, syntax, comments and your first program.

02 — CORE CONCEPTS

Variables & Data Types

Variables, strings, numbers, Boolean values and type conversion.

03 — LOGIC

Operators & Conditions

Operators, if, elif, else and decision-making logic.

04 — REPETITION

Loops

For loops, while loops, break, continue and nested loops.

05 — COLLECTIONS

Python Data Structures

Lists, tuples, sets, dictionaries and common operations.

06 — REUSABLE CODE

Functions

Parameters, arguments, return values, scope and lambda.

07 — PRACTICAL PYTHON

Strings, Files & Errors

String methods, file handling and exception handling.

08 — PROGRAM DESIGN

Object-Oriented Python

Classes, objects, inheritance and reusable program structures.

09 — NEXT LEVEL

Libraries & APIs

Explore Python libraries, databases and API development.

10 — AUTOMATION

Automation & Data

Automate everyday tasks and get started with data analysis.

11 — BUILD

Practice Projects

Apply what you learn by building useful beginner projects.

12 — KEEP GROWING

Advanced Topics

Continue into decorators, generators, testing and more.
