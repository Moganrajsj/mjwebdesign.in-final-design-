Python Tutorial

Learn Python programming from the very beginning. Every topic is explained in simple language with practical examples, code, output, visual logic and exercises.

How to use this tutorial: Read one concept, understand the example, predict the output, then try changing the code yourself. You do not need previous programming experience.

What is Python?

Python is a general-purpose programming language. It is known for readable syntax, a large collection of libraries and use in web development, automation, data analysis, artificial intelligence and many other fields.

Your first Python program

The print() function displays information on the screen.

first_program.py
print("Hello, world!")
Hello, world!

Explanation: Python reads the instruction and calls print(). The text inside quotation marks is displayed as output.

Where is Python used?

Web developmentData scienceAI & machine learningAutomationEducationAPIs

1. Install Python

Download Python from the official Python website. During Windows installation, select Add Python to PATH. Then open Command Prompt or a terminal and check the installed version.

Terminal
python --version

You can write Python in IDLE, Visual Studio Code, PyCharm, Jupyter Notebook or another editor. Choose one editor and practise consistently.

2. Python Syntax and Indentation

Syntax means the rules used to write valid code. Python uses indentation (spaces at the beginning of a line) to group statements. Four spaces are the common convention.

syntax_example.py
age = 20

if age >= 18:
    print("You are an adult")
    print("You can register")
You are an adult You can register

The two indented print statements belong to the if block. Incorrect indentation can cause an IndentationError.

3. Python Comments

Comments are notes for people reading the code. Python ignores comments when executing a program. A single-line comment starts with #.

comments.py
# Store the learner's name
name = "Anu"

print(name)  # Display the name
Anu

4. Print and Input

print() displays a value. input() pauses the program and reads text entered by the user. The value returned by input() is a string.

user_input.py
name = input("Enter your name: ")
print("Welcome,", name)
Enter your name: Kavi Welcome, Kavi
The sample input above is illustrative. When you run the program, enter your own name in the terminal.

5. Python Variables

A variable is a name that refers to a value. Create one by assigning a value with =. Python works out the type from the value.

variables.py
student_name = "Arun"
age = 21
course = "Python"

print(student_name)
print(age)
print(course)
Arun 21 Python

Use descriptive names such as total_price. Names are case-sensitive, cannot begin with a number and cannot be Python keywords.

Variable assignment
age = 21→name: age→value: 21

7. Type Conversion

Type conversion changes a value from one type to another. Common conversion functions include int(), float() and str().

type_conversion.py
age_text = "24"
age = int(age_text)

height = float("1.72")

print(age + 1)
print(height)
25 1.72
Not every string can be converted to a number. For example, int("hello") raises a ValueError.

9. Python Strings

A string is text enclosed in single, double or triple quotes. Strings are ordered sequences, so you can access characters by index and take slices.

strings.py
language = "Python"

print(language[0])
print(language[0:3])
print(language.upper())
print(f"I am learning {language}")
P Pyt PYTHON I am learning Python

String indexes start at zero. Strings are immutable: methods return new strings rather than changing the original string in place.

10. Python If, Elif and Else

Conditional statements let a program choose which block to run based on a condition. Python executes the first matching branch.

conditions.py
mark = 76

if mark >= 90:
    print("Grade A")
elif mark >= 60:
    print("Grade B")
else:
    print("Keep practising")
Grade B
Decision flow
Start→Check mark→Choose matching grade→End

The condition is checked from top to bottom. Only the first true branch runs.

11. Python For and While Loops

A loop repeats a block of code. Use a for loop to go through items in a sequence. Use a while loop to repeat while a condition remains true.

For loop example

for_loop.py
for number in range(1, 4):
    print(number)
1 2 3

While loop example

while_loop.py
count = 1

while count <= 3:
    print(count)
    count += 1
1 2 3
Loop logic
Initialise→Check condition→Run body↺Check again

When the condition becomes false, the loop finishes.

Make sure a while-loop condition can eventually become false. Otherwise, the loop may run forever.

12. Break, Continue and Pass

break exits the nearest loop. continue skips to the next iteration. pass is a placeholder that does nothing.

loop_control.py
for number in range(1, 6):
    if number == 3:
        continue
    if number == 5:
        break
    print(number)
1 2 4

13. Python Lists

A list stores multiple items in one ordered, changeable collection. Lists allow duplicate values and can contain different data types.

lists.py
fruits = ["apple", "mango", "orange"]

fruits.append("grape")
fruits[1] = "banana"

print(fruits)
print(fruits[0])
['apple', 'banana', 'orange', 'grape'] apple

Useful methods include append(), extend(), insert(), remove(), pop() and sort().

14. Python Tuples

A tuple is an ordered collection that cannot be changed after creation. It is useful for fixed groups of values.

tuples.py
location = (11.75, 78.16)

print(location[0])
print(len(location))
11.75 2

A tuple with one item needs a trailing comma: single = (5,).

15. Python Sets

A set is an unordered collection of unique items. It automatically removes duplicates and supports mathematical set operations.

sets.py
colours = {"red", "blue", "red"}
colours.add("green")

print("blue" in colours)
print(len(colours))
True 3

Set display order is not guaranteed. Use sets when uniqueness and membership checks matter.

16. Python Dictionaries

A dictionary stores data as key-value pairs. Keys are unique and are used to look up their corresponding values.

dictionaries.py
student = {
    "name": "Meena",
    "age": 20,
    "course": "Python"
}

print(student["name"])
student["age"] = 21
print(student.get("age"))
Meena 21

Use get() when a key might be missing. It can return a default value instead of raising a KeyError.

17. Python Functions

A function is a reusable block of code. Define it with def, pass information through parameters and send a result back with return.

functions.py
def calculate_total(price, quantity):
    total = price * quantity
    return total

bill = calculate_total(50, 3)
print(bill)
150
Function flow
Input arguments→Function runs→Return value

Functions help reduce repeated code and make programs easier to test and maintain.

18. Modules and Packages

A module is a Python file containing reusable code. Import modules to use their functions and values. A package groups related modules.

modules.py
import math

print(math.sqrt(81))
print(math.pi)
9.0 3.141592653589793

Install third-party packages with python -m pip install package-name. Only install packages from sources you trust.

19. Lambda Functions

A lambda is a small anonymous function written as a single expression. It is useful for short operations, often when passing a function to another function.

lambda.py
double = lambda number: number * 2

print(double(6))
12

For complex logic or reusable operations, prefer a regular function defined with def.

20. File Handling

Python can read and write files. The with statement is recommended because it closes the file automatically when the block finishes.

file_handling.py
with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("Learning Python")

with open("notes.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)
Learning Python

Common modes include "r" for reading, "w" for writing (replaces existing content), "a" for appending and "x" for creating a new file.

21. Exception Handling

Exceptions are errors that occur while a program runs. Use try and except to handle expected error conditions gracefully.

exceptions.py
try:
    number = int(input("Enter a number: "))
    print(100 / number)
except ValueError:
    print("Please enter a whole number.")
except ZeroDivisionError:
    print("The number cannot be zero.")

Catch specific exceptions where possible. Avoid a broad except: that hides unexpected problems.

22. Working with JSON

JSON is a common text format for exchanging structured data. Python's built-in json module converts between JSON text and Python objects.

json_example.py
import json

person = {"name": "Ravi", "age": 22}
json_text = json.dumps(person)

print(json_text)
print(json.loads(json_text)["name"])
{"name": "Ravi", "age": 22} Ravi

23. Classes and Objects (OOP)

Object-oriented programming groups data and behaviour into objects. A class describes how objects of that type are created. An object is an instance of a class.

classes.py
class Student:
    def __init__(self, name, course):
        self.name = name
        self.course = course

    def introduce(self):
        print(f"I'm {self.name}, learning {self.course}.")

student = Student("Asha", "Python")
student.introduce()
I'm Asha, learning Python.

__init__() initialises a new object. self refers to the current instance.

24. Inheritance

Inheritance allows a new class (child) to reuse and extend the behaviour of another class (parent).

inheritance.py
class Animal:
    def speak(self):
        print("Animal makes a sound")

class Dog(Animal):
    def bark(self):
        print("Woof!")

pet = Dog()
pet.speak()
pet.bark()
Animal makes a sound Woof!

25. Iterators and Generators

An iterator produces values one at a time. A generator is a convenient way to create an iterator using yield, which pauses the function and resumes it when the next value is requested.

generators.py
def count_up_to(limit):
    number = 1
    while number <= limit:
        yield number
        number += 1

for value in count_up_to(3):
    print(value)
1 2 3

26. Decorators

A decorator wraps a function to add behaviour without changing the function's original code. Decorators are commonly used for logging, timing and access checks.

decorators.py
def announce(func):
    def wrapper():
        print("Starting...")
        func()
        print("Finished.")
    return wrapper

@announce
def greet():
    print("Hello!")

greet()
Starting... Hello! Finished.

This is a simple teaching example. Production decorators often use functools.wraps to preserve function metadata.

28. Python and APIs

An API lets programs communicate. Python applications often send HTTP requests to an API and receive data, commonly in JSON format. Use a trusted API and protect private credentials.

api_concept.py
# Install first: python -m pip install requests
import requests

response = requests.get(
    "https://api.github.com",
    timeout=10
)

print(response.status_code)

This example requests a public endpoint. Network access is required when you run it.
