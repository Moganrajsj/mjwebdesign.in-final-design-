What Is an LLM Context Window? Tokens, Limits and Practical Tips

A context window is the amount of information a language model can take into account in a single interaction or request. It is usually measured in tokens, not words. The limit includes more than just the latest message.

By MJ WEB DESIGNS · Published 8 November 2026

What is a token?

A token is a chunk of text processed by a language model. It may be a whole word, part of a word, punctuation or another unit. Token counts vary by language, formatting and tokenizer, so a token is not the same as a word.

What counts toward the context window?

The conversation history, system and developer instructions, user prompt, retrieved documents, tool outputs and generated response can all use context. The exact accounting depends on the model and product.

A bigger window is not perfect memory

A model with a large context limit can accept more material, but it may still miss details, confuse similar passages or give more weight to some parts than others. Long input does not guarantee accurate recall.

Context window versus output limit

The context window is the total working space for the request, while the maximum output limit controls how much the model can generate in a response. A model may support a large input context but a smaller maximum answer.

How to work with long documents

Provide a clear task, organise source material with headings, identify the sections that matter and ask for references to exact passages. For large projects, retrieve relevant chunks rather than pasting everything into every prompt.

What about context caching?

Some APIs support caching repeated prompt content to reduce latency or cost. Caching does not necessarily increase the model's context limit; it changes how repeated input is processed or billed.
